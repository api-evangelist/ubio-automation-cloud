# UBIO Automation Cloud

> UBIO (ubio.ai) is a London-based web automation company. Its Automation Cloud runs automation scripts as jobs through a REST API — automating end-to-end website flows like flight and hotel booking, broadband signup, insurance quotes, and job applications — with typed input/output schemas defined by the ubio Automation Protocol.

Generated by API Evangelist from apis.yml and repo artifacts on 2026-07-21 (no provider-published llms.txt was found).

## APIs

- [Automation Cloud API client (JavaScript/TypeScript)](https://github.com/automationcloud/client-javascript): Official client for the jobs API at https://api.automationcloud.net
- [ubio Automation Protocol Reference](https://protocol.automationcloud.net/): Typed input/output schemas for 50+ automation domains
- [OIDC discovery (automationcloud realm)](https://auth.automationcloud.net/auth/realms/automationcloud/.well-known/openid-configuration): OAuth2/OIDC endpoints for API authentication

## Specs

- [Automation Protocol schema.json](https://protocol.automationcloud.net/schema.json): Machine-readable JSON Schema catalog of all automation domains, inputs, outputs, and error codes

- [@automationcloud/client](https://www.npmjs.com/package/@automationcloud/client): Official JS/TS client for the Automation Cloud API

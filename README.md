# UBIO Automation Cloud

UBIO (ubio.ai, formerly ub.io) is a London-based, Techstars-backed web automation company. Its Automation Cloud platform runs automation scripts as jobs through a REST API at api.automationcloud.net — automating end-to-end website flows such as flight and hotel booking, broadband signup, insurance quotes, and job applications — with the ubio Automation Protocol defining typed input/output schemas for 50+ automation domains.

- Website: https://ubio.ai/
- API client: https://github.com/automationcloud/client-javascript
- Protocol reference: https://protocol.automationcloud.net/
- GitHub: https://github.com/ubio and https://github.com/automationcloud

This repository profiles UBIO's API surface for the API Evangelist network, including packages, authentication, error catalog, conventions, data model, well-known documents, and derived MCP candidate tooling. See `apis.yml` for the index.
